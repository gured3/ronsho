論証カード　はじめにお読みください
==================================

■ 中身
  index.html ............ アプリ本体
  sw.js / manifest.webmanifest / *.png ... オフライン起動とアイコン用
  （6つのファイルは必ず同じフォルダに置いてください）


■ iPhone・iPad で使う（最初に1回だけ、ネットにつながった状態で）
iPhoneはファイルを直接開いてもアプリとして動かないため、無料の GitHub Pages に置きます。
  1. https://github.com でアカウントを作る
  2. 右上の「＋」→「New repository」→ 名前（例：ronsho）→ Public → Create repository
  3. 「uploading an existing file」を押し、このフォルダの6ファイルをまとめてドラッグ →「Commit changes」
  4. Settings → Pages → Branch を「main」「/(root)」にして Save
  5. 数分後、https://（ユーザー名）.github.io/ronsho/ で開けるようになる
  6. iPhone・iPadの Safari でそのURLを開く → 共有ボタン →「ホーム画面に追加」
  7. 以後はホーム画面のアイコンから起動。機内モードでも動きます。
  ※ 公開されるのはアプリの部品だけです。作ったカードは各端末の中にだけ保存され、ネットには出ません。
  ※ iPhoneでは「Safariのタブ」と「ホーム画面のアイコン」で保存場所が別です。必ずアイコンから使ってください。


■ Windows で使う（どちらか）
  A. 上の URL を Edge で開く → 右上「…」→「アプリ」→「このサイトをアプリとしてインストール」
     → スタートメニューから起動。オフラインでも動きます。（おすすめ）
  B. このフォルダを好きな場所に置き、index.html をダブルクリック（Edge か Chrome で開く）。
     ネット不要。※あとでフォルダを移動すると、別のアプリ扱いになりカードが見えなくなります。


■ 端末間でカードを移す・バックアップ
  データは端末ごとに保存され、自動では同期しません。
  「設定」→「書き出す」で1つのファイル（.json）になります。iCloud Drive や OneDrive に保存し、
  別の端末で「設定」→「読み込む（追加・更新）」を選ぶと移せます。
  端末の故障や削除に備えて、ときどき書き出してください。


■ アプリを新しい版に更新するとき
  GitHub の同じリポジトリを開き「Add file」→「Upload files」で新しいファイルを全部ドラッグ（同じ名前は上書きされる） → アプリをネット接続中に2回起動すると更新されます。
  カードは消えません。


■ 主な操作
  ・カード作成：「カード」→「＋ 新規カード」。表＝関係図・典型例・キーワード、裏＝ニックネーム・条文番号／判例日時・暗記事項。
  ・関係図：編集画面の「✏️ 関係図を描く」で、ペン・矢印・文字を使って描ける（画像・文字でも可）。
  ・隠す：文字を選んで「隠す」。学習中は灰色の帯になり、タップで表示。
  ・マーカー：文字を選んで 黄・桃・青・緑。
  ・手書き：学習画面の「手書き」をオンにしてカードに直接書く（iPadは「設定」で Pencil のみにすると指でスクロールできる）。
  ・画像：編集画面の「＋ 表に画像」「＋ 裏に画像」。パソコンでは貼り付け（Ctrl+V）でも可。
  ・まとめて追加：Excel 等で「ニックネーム｜関係図（文字）｜典型例｜キーワード｜条文番号・判例日時｜暗記事項｜科目｜分野」の順に並べ、コピーして貼り付け。
  ・キーボード：Space/Enter＝答え、1/2/3＝○△✖、U＝取消、Esc＝終了。

  「民法（サンプル）」の6枚は見本です。内容はご自身の教材で確認のうえ、不要なら「設定」から削除してください。
